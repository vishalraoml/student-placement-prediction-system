# Student Performance & Salary Prediction System

Machine Learning and Power BI analytics project for predicting student salary packages using academic and skill-based attributes.

# Project Overview

This project analyzes student academic performance, technical skills, internships, certifications, and other factors to predict expected salary packages using Machine Learning.

The system includes:
- Salary prediction model using Random Forest Regression
- Interactive Streamlit web application
- Power BI analytics dashboard
- Data preprocessing and visualization pipeline

# Technologies Used

- Python
- pandas
- NumPy
- scikit-learn
- matplotlib
- seaborn
- Streamlit
- Power BI
- Git & GitHub

# Machine Learning Features

- Data Cleaning
- Feature Engineering
- One-Hot Encoding
- Regression Modeling
- Model Evaluation
- Feature Importance Analysis


# Model Performance

- MAE: ~1.07
- RMSE: ~1.33
- R² Score: ~0.71

# Dashboard Features

- Salary Analytics
- CGPA vs Salary Analysis
- Coding Skills Impact
- Internship Impact
- College Tier Analysis
- Interactive Filters & Slicers
